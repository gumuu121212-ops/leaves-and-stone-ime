# Leaves & Stone data attribution

The `leaves_stone` schema and dictionary manifest are derived from the Rime
Luna Pinyin project maintained by Rime Developers. The complete Luna Pinyin
table and Rime Essay vocabulary are installed during the reproducible data
build by the pinned Plum package manager.

- Luna Pinyin source package: `rime/rime-luna-pinyin`
- Rime Essay source package: `rime/rime-essay`
- Package installer pin: Plum commit `cab9ed35289f2022b6888503750d2dfb1851dbe0`
- Luna Pinyin license: GNU Lesser General Public License v3.0 or later

The upstream license texts and attribution files remain packaged alongside the
application. Leaves & Stone's own configuration changes are distributed under
the repository's GNU GPL v3.0 license.
