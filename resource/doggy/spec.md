## 文件与使用范围

- `mascot-default.png`、`mascot-hover.png`、`mascot-pressed.png`、`mascot-idle.png`：1024 × 1024，8 位每通道、PNG color type 6（RGBA），真实透明。
- default：白色长绒、玳瑁圆眼镜、低脸宽趴姿势，双爪分在两侧。
- hover：相同姿势，仅眼神和高光轻微变化。
- pressed：图像右侧的眼睛眨眼，另一只眼保持睁开，贴近参考图点击态。
- idle：双眼闭合休息，双爪维持原位。
- `mascot-avatar.png`：512 × 512，单独狗头，透明；工具条优先展示完整头部，也可圆裁切。
- `icons/icon-paw.png`：64 × 64。
- `icons/icon-zh.png`、`icon-en.png`、`icon-jp.png`、`icon-kr.png`、`icon-moon.png`、`icon-shirt.png`、`icon-gear.png`：48 × 48，分别为「中 / A / あ / 한 / 月亮 / 衣服 / 设置」。
- `textures/panel-plush.png`：1536 × 288，独立透明绒面胶囊，无文字、图标和狗，用于候选条与工具条。
- `textures/menu-plush.png`：736 × 640，独立透明绒面菜单底图，无文字、图标和狗。
- `spec.md`：本说明。

共 15 张 PNG 与本说明。为复现参考图的绒面与毛边，此版增加两张独立纹理；只画纯色圆角矩形无法得到同样质感。选中胶囊、翻页胶囊、文字与装饰短线仍由代码绘制。

这是供开发接入的素材包，不是可双击安装的输入法程序，也不是 .ssf / .bds 文件。预览由交付素材实际组合，尚未进行输入法进程内运行验证。模糊室内背景仅用于预览，不属于皮肤控件，不在素材 ZIP 内。

## 画布、搭边锚点与比例

坐标以 PNG 左上角为 (0,0)，x 向右、y 向下。

**四帧统一锚点为 (512,620)，固定搭边基线为 y = 620 px。** 基线只用于布局，不画在图片中。

四帧共用内容框 `(342,450,340,188)`。主体采用与新参考图接近的宽趴比例，保持原来的 1024 画布。双爪左右分开，鼻子贴近搭边线；不能再使用上一版的 340 × 260 自动裁剪区域。

- 推荐候选条主宠物比例 `s = 0.6 dip / 图片像素`，可见主体约 204 × 112.8 dip。
- 头顶高出搭边线约 102 dip，双爪和下巴在条沿以下约 10.8 dip。
- 主宠物锚点取候选条宽度的 60.5% 位置：`anchorX = barLeft + barWidth * 0.605`。它位于条子中部偏右，不能缩成靠右的小装饰。
- 完整 PNG 的目标矩形左上角为 `(anchorX - 512*s, barTop - 620*s)`，宽高均为 `1024*s`。
- 若统一裁到内容框，目标左上角为 `(anchorX - 170*s, barTop - 170*s)`，尺寸为 `(340*s,188*s)`。
- 所有状态必须共用同一画布、裁剪框、目标矩形和取整方法，不可逐帧自动去透明边。
- 物理像素 = dip × DPI / 96。先计算浮点坐标，再统一取整。
- 四帧左爪区域 `(344,590,94,48)`、右爪区域 `(596,590,86,48)`，共 8,640 个像素，逐像素复用 default 的 RGBA；这两个区域跨过 y=620。
- default / hover / pressed 的 alpha 通道相同，仅镜片内眼神发生变化。idle 的头部轮廓可轻微变化，双爪不动。
- PNG 为 straight alpha。绘制接口要求 premultiplied alpha 时，在加载阶段转换。
- 鼠标命中采用 alpha ≥ 32 的可见区域，不把整个 1024 透明画布当成可点击范围。

## 绒面底图绘制

候选条与工具条横向比例接近 panel-plush.png，直接完整缩放即可，必须保留整个 alpha 外形；若使用图像库，指定完整缩放，不能使用会裁掉圆角的 cover 模式。

宽度大幅变化时，可用九宫格：源图左右上下各保留 120 px，目标边框约 25–36 dip。边缘与中心应保持纹理比例或无缝平铺，不能把少量纹理纵向拉成长条。菜单直接使用单独的 menu-plush.png，参考尺寸为 184 × 160 dip；预览按其原生尺寸的 0.5 倍绘制，不用候选条纹理强行拉成菜单。

小的选中胶囊和翻页胶囊保持光滑米色 / 米白色，形成与绒面主体相同的层次关系。

## 交互定义

优先级：鼠标 pressed > 上屏眨眼 > 宠物 hover > idle > default。

1. default：正常输入时显示。真实按键、组合串更新、候选翻页与候选选择均重置闲置计时。
2. hover：鼠标进入宠物可见区域并停留 100 ms 后显示；离开时恢复当前状态。仅经过候选条空白或候选字，不触发宠物表情。
3. pressed：宠物上按下鼠标左键时立即显示单眼眨眼帧；松开或失去捕获后恢复，最短 100 ms，持续按住最多 500 ms。反馈不能改变正在输入的内容，也不能抢走焦点。
4. idle：12 秒没有上述输入活动，且鼠标未按住、未悬停宠物、没有正在播放眨眼时，切到双眼闭合休息。重新输入立即唤醒。候选窗口隐藏时，不为显示宠物而保留空窗口；可由独立工具条承接休息态。
5. 上屏反馈：宿主确认候选成功提交后，播放 pressed 帧 110 ms，再回 default / hover。250 ms 内多次提交合并一次；普通按键不逐字触发。鼠标 pressed 优先，释放后不补播过期反馈。
6. 减少动态效果：系统或用户关闭动画时停止自动上屏反馈与 idle 定时切换，保持 default；按钮保留基本交互反馈。

直接替换帧，不对不同状态独立缩放、移动或淡入淡出，避免眼镜重影。

## 导出核验
