# 小狗悬浮状态栏素材

本包只包含参考图下方圈出的悬浮状态栏板块，可独立用于开发；不依赖之前的 doggy-skin.zip。

## 从这里使用

- `states/toolbar-default.png`：默认，大狗头位于条子左侧。
- `states/toolbar-hover.png`：悬停，双爪搭边，带动感线。
- `states/toolbar-pressed.png`：点击，单眼眨眼，带心形。
- `states/toolbar-idle.png`：闲置，闭眼趴在绒垫上，带爪印与 z 装饰。
- 四张均为 **896 × 480、PNG-32 RGBA、真实透明**，整块外面的空间没有房间背景、棋盘格或状态文字。
- 原生素材按 4 倍比例制作，整张画布对应 **224 × 120 dip**；按钮与绒面条在画布下部，上方为宠物和装饰预留透明空间。
- `preview.png` 是浅色棋盘 / 深灰底检查图，仅用于查看效果，不作为界面图片加载。

这四张是已经组合好的静态外观，可直接用于原型或按命中区域处理按钮。需要实时切换中 / A / あ / 한、单个按钮悬停反馈或隐藏装饰时，使用下述独立图层。

## 分层绘制

`layers/toolbar-{状态}.png` 是相同画布尺寸的“狗 + 底条”组合，**不包含可操作按钮和悬停 / 点击 / 睡眠装饰**。idle 底图包含右侧爪印。绘制顺序：

1. 当前状态的 `layers/toolbar-*.png`。
2. 如鼠标经过或按住某个按钮，在对应点击区域绘制 `controls/button-hover.png` 或 `button-pressed.png`。
3. 模式按钮 `controls/mode-zh.png` / `mode-en.png` / `mode-jp.png` / `mode-kr.png`，以及月亮、衣服、设置三个图标。
4. 可选的 `decorations/hover.png` / `pressed.png` / `idle.png`。

已经使用 `states/` 完整图时，不要再次叠加按钮或装饰，否则会出现重影。完整图固定显示中文模式；动态语言模式应走分层绘制。

各组件单独图片也保存在 `layers/`：默认狗头、悬停狗、点击狗、睡眠狗、正常底条、闲置底条、闲置爪印；均为本包实际使用的透明素材，可以自行重新排版。按钮的底色和白色模式字形也已分别保存在 `controls/`。

## 坐标与 DPI

全部机器可读布局见 **layout.json**。其中矩形均为原生素材像素 `[x,y,width,height]`，不是 dip；图层使用源图完整尺寸绘制到给定位置。

- 画布：896 × 480 px = 224 × 120 dip。
- 固定右下锚点：(832,448) px = (208,112) dip。状态切换复用窗口大小与此锚点。
- 原生坐标变成物理像素：`sourcePx * (DPI / 96) / 4`。
- 如果锚点屏幕位置为 `(anchorX,anchorY)`，整张画布左上角为 `(anchorX - 208*DPI/96, anchorY - 112*DPI/96)`。
- 不要按每张图的非透明边界分别裁剪或自动居中。默认狗头与悬停抬头的位置变化是参考图中的设计动作；底条、按钮和窗口锚点保持一致。
- PNG 使用 straight alpha；绘制接口要求 premultiplied alpha 时在加载阶段转换。不要先合成到白底或黑底。
- 透明像素应允许鼠标穿过，不把整张 224 × 120 dip 透明画布当成有效点击区域。

正常底条：`(192,288,640,160)`。闲置绒垫：`(96,320,736,128)`。

| 控件 | 点击区域 px | 图像矩形 px |
|---|---|---|
| 语言模式 | (416,304,100,128) | (434,336,64,64) |
| 月亮 | (520,304,100,128) | (534,332,72,72) |
| 换肤 | (624,304,100,128) | (638,332,72,72) |
| 设置 | (728,304,100,128) | (742,332,72,72) |

点击区域互不相交，小狗不会覆盖这些按钮。按钮是否可用、切换哪种输入语言、打开哪个设置窗口，由开发者连接真实功能。

## 建议交互

- 鼠标进入可见小狗或底条 100 ms 后进入 hover；按钮另叠独立悬停底色。离开后恢复 default。
- 按下鼠标时显示 pressed，最短 100 ms，松开或失去捕获后恢复。按钮操作只在同一个按钮内按下并松开时触发，离开按钮释放则取消。
- 宠物、空白底条可作为拖动区域，四个按钮优先响应点击；不要抢走正在输入应用的键盘焦点。
- 12 秒无输入活动后切换 idle。idle 与参考图一致，收起四个按钮，显示睡眠绒垫；第一次点击可见宠物或绒垫只负责唤醒，防止误触设置。
- 输入或成功上屏立即唤醒。可用 pressed 做 110 ms 的上屏反馈，250 ms 内合并重复反馈。
- 月亮按钮可连接“减少动画 / 宠物休息”；衣服打开皮肤选择；齿轮打开设置；模式按钮打开语言选择。名称和行为均已在 layout.json 给出。
- 系统或用户选择减少动画时，停止自动眨眼、动感线和 z 装饰，可固定 default。
- 如需要控件阴影，建议由程序在可见底条下绘制暖棕色阴影：#604532，alpha 0.18，sigma 4 dip，偏移 (0,3) dip；当前图层没有烘焙环境阴影。

本包交付开发素材和坐标，不包含状态栏程序本身。界面事件、窗口显示、拖动、按钮功能和系统接入仍由宿主实现。
