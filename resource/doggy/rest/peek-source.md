# 小毛豆侧探头素材来源与接入

用户明确纠正了原先倒挂的呈现，并确认“从右侧竖直边缘歪头探进来”的视觉预览。此处两张 PNG 用于落实该姿态；原趴睡工具栏及其分层未改动。

## 素材与许可

- `peek-awake.png`：内置 imagegen 根据用户确认的侧探头预览、原小毛豆透明图层制作，独立完整狗头，不含任何界面边框、背景或胶囊。
- `peek-sleep.png`：先用 imagegen 编辑同一睁眼帧，要求只闭合眼睛；随后以睁眼帧为固定底，仅合入两个镜片内部的闭眼 RGB，保留整个画布的原 alpha 和其余像素。
- 两帧均为 1254×1254，8-bit RGBA PNG，有透明留白及毛发半透明边缘。切换时使用同一窗口矩形，不裁边、不重新居中。
- 原照片由用户提供，用户已确认拥有相应权利并同意衍生素材按 GPL-3.0 再分发。生成图与本项目原素材一并按 GPL-3.0-only 分发，全文见本目录 `LICENSE.txt`。没有拆取第三方皮肤，没有将预览中的合成背景抠成最终资源。

## 生成提示记录

使用内置 imagegen，没有使用 API/CLI 后备方式。

睁眼帧：根据已确认预览中右侧睁眼小狗，保留奶白毛发、玳瑁圆眼镜、黑色眼睛、鼻子、口鼻比例和垂耳；正向面孔轻轻逆时针歪头，左耳自然垂下。补全预览中被边框遮住的头部外侧，输出单独完整狗头，居中、留少量透明边距。不要身体、爪子、工具栏、边框、阴影、文字或背景。请求 1024 方形画布，工具实际返回 1254 方形，接入时保留原尺寸。

闭眼帧：以刚生成的透明睁眼头为编辑目标，只把两个镜片内部的睁眼改为平静闭眼，保留同画布、位置、尺度、倾斜角、耳朵、毛发轮廓、眼镜及鼻子；保持透明背景，不加睡眠符号或其他物体。

原生成输出：睁眼 `exec-9d401fcc-e550-49c6-a740-9b0ace2205d3.png`；闭眼 `exec-c468cf23-1f56-4d5c-a0f6-918037f773a4.png`。这是新姿态的原创图层生成记录，不是从 UI 预览裁图。

对齐合成使用直通 RGBA，固定睁眼 alpha，不改变外形。两个椭圆内区的归一化 `(cx, cy, rx, ry)` 分别是 `(0.433, 0.566, 0.082, 0.076)`、`(0.645, 0.476, 0.083, 0.078)`；闭眼 RGB 的权重为 `clamp((1 - dx² - dy²) / 0.22, 0, 1)`，区外像素完全沿用睁眼图。成品已经合成，运行时无需再做此处理。

## 显示与交互

运行时整张按 `400 × 400 × 0.5 × 0.55 × dpi_scale` 像素显示；100% 缩放时窗口为 110×110 像素，保留图内透明留白。左右贴边时将窗口外侧 22% 放到显示器工作区之外，由实际工作区裁切遮住外侧毛发；右边缘使用原图，左边缘仅水平镜像，不倒转面部。上下边缘保留正向姿态并隐藏外侧 10%，便于继续支持原有四边停靠。

默认闭眼；进入有效毛发区域 60 ms 睁眼，离开 300 ms 闭眼。悬停不展开；向内拖出 8 dip 才恢复完整工具栏，沿边拖动仅调位置。透明留白穿透点击。普通工具栏按钮、拖动阈值、两段各 140 ms 的收起/探出动画保持原交互。

原生回归检查正向原像素对应、左右镜像、两帧 alpha 相同、变化限于眼区、真透明边缘、透明留白命中穿透，以及反复绘制的 GDI 资源释放。
