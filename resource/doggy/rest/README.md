# 小毛豆 · 趴在工具条上（原造型复用版）

两张成品均为 896×480、8 bit RGBA 真透明 PNG。

- toolbar-sleep.png：默认闭眼趴着休息。
- toolbar-awake.png：鼠标移入睁眼。

复用此前已交付的狗、眼镜、毛绒工具条和按钮。没有采用本轮重新生成的另一只狗，没有从截图或概念预览抠图。睁眼图采用原 mascot-hover；闭眼图只将原 mascot-idle 的两处眼睛局部合入，头部外形、毛发、眼镜、鼻子和爪子均保持睁眼原图。仅有眼区 RGB 改变，alpha、轮廓及工具条逐像素一致。

## 对齐与接入

所有 PNG 图层均使用同一 896×480 画布，直接在同一左上角绘制，不要按各自可见内容裁边或重新居中。图片不包含白底或棋盘格。

- 建议资源倍率：2 倍；整张显示 448×240 dip。透明留白也计入窗口尺寸。
- 共同搭边锚点：图内 (448, 296) px，即 (224, 148) dip。框的上沿在这条线附近，两爪末端自然遮在边缘前方。
- 狗图层矩形：(248, 96, 400, 221) px；主体水平居中，不挪动原造型自身角度。
- 工具条矩形：(128, 288, 640, 160) px，原图自带少量透明边。
- 屏幕点定位：窗口左上角 = 目标搭边锚点 − (448,296)×显示比例。若以 dip 绘图，则减去 (224,148)。

用完整 toolbar-*.png 可直接切换。如需本地绘制不同语言或按钮，使用 layers/panel.png + 自绘按钮 + layers/mascot-*.png；若按钮固定，可直接使用 layers/toolbar.png + mascot。完整成品已含「中、月亮、衣服、设置」，不要重复叠画按钮。

默认闭眼；鼠标进入狗或工具条有效区域后 60ms 睁眼；离开 300ms 后闭眼。两帧按原位替换，无位移或缩放动画。透明外边距可穿透点击。睡眠符号、动感线独立放在 layers/decoration-*.png，可选，不影响主图对齐。

index.html 可离线打开，移动鼠标到图片可查看切换。preview.png 的棋盘格和深色底仅供检查透明边缘，不属于任何素材。具体控件坐标见 layout.json。
