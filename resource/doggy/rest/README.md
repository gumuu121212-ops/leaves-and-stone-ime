# 小毛豆 · 趴在工具条上（原造型复用版）

两张成品均为 896×480、8 bit RGBA 真透明 PNG。

- toolbar-sleep.png：默认闭眼趴着休息。
- toolbar-awake.png：鼠标移入睁眼。
- mascot-sleep.png / mascot-awake.png：原交付包中同画布的独立狗图层，原样保留作为原趴睡姿态的分层来源。
- peek-sleep.png / peek-awake.png：1254×1254 透明侧探头帧，替代原先旋转 180° 的贴边呈现。脸保持正向并轻轻歪头，右边缘遮住外侧毛发；左边缘使用水平镜像。两帧 alpha 完全一致，仅两处眼睛内的 RGB 不同。来源、生成提示与对齐方式见 [peek-source.md](peek-source.md)。

独立图层校验值：`mascot-sleep.png` 为 `FFB7F8D23CE629C67DD1C6FBBC25DD5C37490E286DE910D4A469A2012B085697`，`mascot-awake.png` 为 `152D78E78F7B2302543DDBD23738FFBC0F35D392699CACEE127E532B76C04F6E`。来源与本目录完整工具栏相同，沿用 GPL-3.0-only 和用户已确认的照片衍生授权。

完整工具栏复用此前已交付的狗、眼镜、毛绒工具条和按钮。toolbar-*.png 的睁眼图采用原 mascot-hover；闭眼图只将原 mascot-idle 的两处眼睛局部合入，头部外形、毛发、眼镜、鼻子和爪子均保持睁眼原图。侧探头是用户另行确认的新姿态，制作过程见上述来源说明；没有从界面截图抠取最终图像。

## 对齐与接入

原趴睡工具栏图层使用同一 896×480 画布，直接在同一左上角绘制，不要按各自可见内容裁边或重新居中。侧探头两帧使用同一 1254×1254 画布，运行时按等比例方形绘制。图片不包含白底或棋盘格。

- 建议资源倍率：2 倍；整张显示 448×240 dip。透明留白也计入窗口尺寸。
- 共同搭边锚点：图内 (448, 296) px，即 (224, 148) dip。框的上沿在这条线附近，两爪末端自然遮在边缘前方。
- 狗图层矩形：(248, 96, 400, 221) px；主体水平居中，不挪动原造型自身角度。
- 工具条矩形：(128, 288, 640, 160) px，原图自带少量透明边。
- 屏幕点定位：窗口左上角 = 目标搭边锚点 − (448,296)×显示比例。若以 dip 绘图，则减去 (224,148)。

用完整 toolbar-*.png 可直接切换。如需本地绘制不同语言或按钮，使用 layers/panel.png + 自绘按钮 + layers/mascot-*.png；若按钮固定，可直接使用 layers/toolbar.png + mascot。完整成品已含「中、月亮、衣服、设置」，不要重复叠画按钮。

默认闭眼；鼠标进入狗或工具条有效区域后 60ms 睁眼；离开 300ms 后闭眼。两帧按原位替换，无位移或缩放动画。透明外边距可穿透点击。睡眠符号、动感线独立放在 layers/decoration-*.png，可选，不影响主图对齐。

index.html 可离线打开，移动鼠标到图片可查看切换。preview.png 的棋盘格和深色底仅供检查透明边缘，不属于任何素材。具体控件坐标见 layout.json。
