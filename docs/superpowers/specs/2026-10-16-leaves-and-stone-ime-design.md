# Leaves & Stone 输入法设计规格

日期：2026-10-16  
状态：待用户审阅  
目标版本：1.0 测试版

## 1. 产品目标

Leaves & Stone 是一款可由普通用户安装并在 Windows 输入法列表中切换使用的桌面中文输入法。第一版面向 Windows 10 与 Windows 11，提供简体全拼和英文直输。它不是现有输入法的皮肤文件，也不是候选框演示程序；验收标准是用户完成安装后，可以在记事本、Office、浏览器、微信和 Electron 应用中进行日常中文输入。

产品的识别点是候选窗口。视觉采用用户确认的建筑与植物水粉插画：暖白底、砖红建筑、橄榄绿树叶、浅天蓝天空和黑色建筑线稿。候选项不放在统一外框内，而是以独立、凸起的 3D 纸雕按键悬浮在光标附近。

## 2. 第一版范围

### 2.1 包含

- Windows 10、Windows 11，x64 安装；同时提供 32 位应用所需的兼容注册与组件。
- 简体中文全拼输入。
- 英文直输模式。
- 中英文标点切换。
- 候选词生成、数字键选词、空格确认、方向键切换、翻页、退格和 Esc 取消。
- 用户词频学习与本地用户词典。
- 固定的 Leaves & Stone 视觉主题。
- 候选词数量、字号、横排/竖排、动画开关等少量设置。
- 安装、修复安装、卸载和可选保留用户词典。
- 本地诊断日志。
- GPL-3.0 开源发布，并保留上游项目许可证和来源说明。

### 2.2 不包含

- 账号系统、云同步、云词库。
- 皮肤商店、主题导入或用户换图。
- 手机端、macOS、Linux。
- 双拼、五笔、手写、语音、繁体模式。
- 自动更新和后台常驻广告服务。
- 正式商业代码签名；测试阶段使用明确提示的测试证书。

## 3. 技术路线

项目基于 Rime 的 Windows 前端 Weasel 深度改造，并使用 librime 作为输入引擎。

选择该路线的原因：

- Weasel 已实现 Windows Text Services Framework（TSF）接入、输入法注册、候选处理和安装基础。
- librime 已提供成熟的拼音解析、候选生成、用户词频和词典能力。
- 第一版可以把主要开发精力放在可靠安装、品牌隔离和候选窗口重做，而不是重新实现中文输入算法。
- Weasel 使用 GPL-3.0，项目接受以相同许可证公开衍生代码；librime 使用 BSD-3-Clause。

现代 Windows 第三方 IME 必须通过 TSF 工作。Leaves & Stone 不使用已被系统限制的旧式 IMM32 实现。

## 4. 系统组成

### 4.1 TSF 输入前端

负责接收键盘事件、跟踪当前编辑上下文、确定候选窗口锚点，并将确认后的文字提交到当前应用。它沿用 Weasel 已验证的 TSF 生命周期和 32/64 位兼容结构，仅在品牌标识、配置入口和候选界面连接层上做定向修改。

### 4.2 Rime 输入引擎

负责拼音组合、候选词、词频学习和本地词典。默认方案只启用简体全拼，避免第一版暴露大量 Rime 配置。用户数据与程序文件分离，修复安装不覆盖用户词频。

### 4.3 候选窗口渲染器

使用 Windows 原生图形能力渲染独立候选键、阴影、文字与透明插画素材。渲染器接收统一的候选模型，不直接读取词库：

1. TSF 前端提交当前拼音组合。
2. librime 返回候选列表、选中索引和分页状态。
3. 界面模型计算每个候选键的位置、尺寸和可点击区域。
4. 渲染器绘制拼音浮牌、候选键、翻页按钮和装饰层。
5. 用户通过键盘或鼠标选词，结果回到 TSF 前端并写入应用。

### 4.4 设置程序

设置程序与 IME DLL 分离，避免将复杂界面和不必要依赖加载进每个宿主应用。第一版只提供：

- 候选数：5、7 或 9。
- 字号：小、中、大。
- 横排或竖排。
- 动画启用/禁用。
- 装饰启用/禁用。
- 恢复默认设置。

配置采用本地文件保存。IME 监听配置变化并安全刷新候选窗口。

### 4.5 安装器

安装器负责部署文件、注册 TSF 文本服务、安装开始菜单入口、添加卸载信息和执行修复。测试版包含自签名测试证书，并在安装前明确说明用途、发布者状态和导入位置；用户必须主动确认。卸载时让用户选择保留或删除个人词典。

## 5. 候选窗口设计

### 5.1 结构

- 光标旁显示一块较小的拼音浮牌。
- 下方默认显示 5 个彼此分离的候选键。
- 翻页、语言状态与设置入口使用独立圆形按钮。
- 不绘制包围所有内容的统一大底板或边框。
- 装饰层位于候选键后方、间隙和少数前景边缘，不进入文字安全区。

### 5.2 视觉规则

- 背景基色：暖象牙白。
- 主色：砖红、橄榄绿、深叶绿、浅天蓝和炭黑。
- 默认候选键：暖白纸雕材质，圆角、可见厚度、柔和边缘高光和落影。
- 选中候选键：淡天蓝，整体抬高约 4 个逻辑像素，阴影略加深。
- 插画素材：从 `docs/assets/visual-reference.png` 提取和重绘为透明分层素材，不直接把整张图铺在窗口背景上。
- 建筑、树叶和天空只承担品牌氛围，不能降低候选文字对比度。
- 字体优先使用 Windows 自带、覆盖简体中文且在小字号下清晰的字体；不随安装器分发版权不明确的字体。

### 5.3 动效

- 候选窗口首次出现：约 140ms 轻微上浮与淡入。
- 选中项变化：只更新抬高、颜色和阴影，避免整组移动。
- 翻页：候选键短距离交叉淡化，不使用旋转或弹跳。
- 关闭动画后，所有状态在一帧内完成。

### 5.4 缩放和定位

- 支持 100%、125%、150%、200% Windows 缩放。
- 根据当前显示器 DPI 计算尺寸。
- 优先显示在光标下方；空间不足时移到上方。
- 防止超出工作区、压住任务栏或跨显示器错误跳动。

## 6. 交互规则

- `1`–`9`：选择对应候选。
- `Space`：确认当前候选。
- `Left` / `Right`：移动选中项。
- `PageUp` / `PageDown`：前后翻页。
- `Backspace`：删除一个组合字符。
- `Esc`：取消当前组合。
- 中英文切换沿用 Windows 用户熟悉的快捷方式，并在设置中显示当前绑定。
- 鼠标可以点击候选键和翻页按钮。
- 英文模式下不显示候选窗口，除非用户进入明确的中文输入状态。

## 7. 容错与安全

- librime 初始化失败时，候选窗口显示简短错误状态并提供打开日志目录的入口，不循环弹窗。
- 单次渲染失败时关闭候选窗口并记录错误，不能使宿主应用崩溃。
- 配置文件损坏时回退到内置默认值，并备份损坏文件。
- 日志不记录用户已提交的完整文本；只记录版本、错误码、组件状态和必要的匿名技术信息。
- 输入法不联网，不读取与输入无关的文件，不注入广告或遥测。
- 测试证书安装必须由用户确认，卸载文档说明如何移除证书。

## 8. 安装与发布

### 8.1 测试版

- 生成可执行安装包。
- 使用项目测试证书签名构建产物。

## 9. 测试与验收

### 9.1 自动测试

- 候选模型：分页、索引、选中状态和空候选。
- 布局：不同候选长度、DPI 和屏幕边缘定位。
- 配置：默认值、损坏文件回退和热刷新。
- 输入状态：中文、英文、标点、取消和连续提交。
- 安装脚本：安装、修复、卸载和重复执行。

### 9.2 手工兼容测试

目标应用：

- Windows 记事本。
- Microsoft Word。
- Edge 与 Chrome。
- 微信桌面版。
- Obsidian 等 Electron 应用。

环境组合：

- Windows 10 x64 与 Windows 11 x64。
- 100%、125%、150%、200% 缩放。
- 单显示器与双显示器。
- 明亮与深色宿主应用。
- 32 位与 64 位输入框宿主。

### 9.3 版本完成标准

1. 用户可通过安装包完成安装，并在 Windows 输入法列表中看到 Leaves & Stone。
2. 上述目标应用可以稳定输入简体中文与英文。
3. 候选窗口无统一外框，候选项为独立 3D 纸雕键，视觉与参考图一致。
4. 高分屏和屏幕边缘不出现明显裁切或错位。
5. 卸载后输入法注册被移除；根据用户选择保留或删除词典。
6. 关键自动测试通过，手工兼容矩阵没有阻断日常使用的问题。
